Frontier original soundscapes

These seven deterministic arrangements and weather textures were authored for
Frontier in FrontierSoundscapeAssets.cs. They do not contain third-party music,
samples, quotations, or imitations of an existing composition.

The editor bakes three 16-second A-minor arrangements (exploration, combat and
travel) and four 8-second weather textures. Runtime playback never synthesizes
these sounds. The soundtrack changes arrangement by fading through silence on
one Music-bus source; weather uses the existing SFX bed outside travel.

Use Frontier > Audio > Create Original Soundscapes If Missing only to bootstrap
missing assets. Existing library mappings and recordings are preserved. Edit
SoundscapeLibrary.asset to replace loops or adjust gain and transition duration.

The engine is NOT original material: its source and looped derivative live in
KenneySciFi beside Kenney's original CC0 license.
